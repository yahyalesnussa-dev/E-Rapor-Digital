      Petunjuk Penggunaan Aplikasi E-Rapor

      Pilih tab sesuai dengan peran (role) Anda di sekolah.

      Tugas & Wewenang Administrator

      • Pengaturan Sekolah: Pastikan Anda mengisi nama sekolah, nama kepala sekolah, NIP, serta Tahun Ajaran yang aktif di menu Pengaturan Sekolah.
      • Master Data: Admin wajib melengkapi Data Kelas dan Data Mata Pelajaran sebelum guru dapat menginput nilai.
      • Manajemen Akun: Tambahkan akun untuk setiap Wali Kelas dan Guru Mapel di menu Pengaturan Akun. Berikan username dan password sementara kepada mereka.
      • Backup Data: Sangat disarankan untuk melakukan Export Data (Unduh JSON) seminggu sekali di menu Backup Data sebagai cadangan agar nilai tidak hilang jika browser dibersihkan.
      Catatan Penting: Kode Keamanan Sekolah (untuk fitur Lupa Password) default-nya adalah: NAMROLE16. Beritahukan kode ini hanya kepada rekan guru yang membutuhkan reset sandi.

      Panduan Guru Mata Pelajaran & Wali Kelas

      • Login: Masuk menggunakan Username dan Kata Sandi yang diberikan oleh Operator Sekolah, atau daftar melalui tautan pendaftaran di halaman depan.
      • Data Siswa (Wali Kelas): Wali Kelas bertanggung jawab untuk menambahkan nama siswa beserta NISN ke dalam kelas yang diampunya melalui menu Data Siswa.
      • Input Nilai (Semua Guru): Buka menu Input Nilai, pilih Kelas, lalu pilih Mata Pelajaran yang Anda ajar.
      • Masukkan nilai rata-rata Formatif, dan nilai Sumatif. Nilai akhir akan dihitung secara otomatis.
      • Isi Capaian Kompetensi dengan mendeskripsikan kelebihan (tertinggi) dan hal yang perlu bimbingan (terendah) siswa tersebut.
      • Cetak Rapor (Wali Kelas): Pada akhir semester, Wali Kelas dapat membuka menu Cetak Rapor, memilih siswa, lalu menekan tombol Cetak Dokumen untuk menge-print atau menyimpan sebagai PDF.

      Panduan Kepala Sekolah

      • Akses Pemantauan: Kepala sekolah dapat masuk ke sistem untuk memantau progres pengisian e-rapor oleh para guru.
      • Dashboard: Lihat ringkasan total siswa, jumlah rombel/kelas, dan total data nilai yang sudah masuk.
      • Pengecekan Nilai: Buka menu Cetak Rapor untuk meninjau hasil belajar (rapor) siswa secara acak (sampling) sebelum dokumen resmi dicetak dan ditandatangani.

      Panduan Install Aplikasi (PWA) & Reset Lupa Password

      Android & Laptop (Chrome / Edge)
      1. Klik tombol Install App / Install Aplikasi pada bilah atas atau sidebar kiri.
      2. Konfirmasi dialog "Install" yang muncul di browser Anda.
      3. Ikon E-Rapor SDN 16 Namrole akan otomatis terpasang di layar utama / desktop.
      iPhone / iPad (Safari)
      1. Buka aplikasi menggunakan browser Safari.
      2. Ketuk ikon Bagikan (Share) di bagian bawah layar.
      3. Pilih Tambah ke Layar Utama (Add to Home Screen) lalu ketuk Tambah.

      Cara Mengatasi Lupa Password:

      1. Pada halaman Login, klik tautan "Lupa Sandi?".

      2. Masukkan Username akun Anda dan Kode Keamanan Sekolah (NAMROLE16).

      3. Ketik Kata Sandi Baru lalu klik tombol Reset Sandi.
